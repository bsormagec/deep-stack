Someone scraped 47K GitHub pull requests and found something wild.

A new vocabulary cluster appeared in 2026. It now makes up 45% of all human-attributed PRs last month.

"Load-bearing" is 123× more frequent than baseline. "Quietly", "latent", "genuinely", "byte-identical", "refusal" — all spiking together.

Claude is building its own dialect. Humans are absorbing it into their own writing without noticing. Even HN commenters caught themselves mid-sentence: "I've recently caught myself using them in conversations."

This is what AI-native language looks like — not in chatbots, but in the code humans write.
